# Sana Sales Intelligence

سامانه هوشمند ارزیابی، تشخیص و مدیریت فروش کسب‌وکارها

## معرفی

Sana Sales Intelligence یک افزونه و زیرساخت مدیریتی مبتنی بر WordPress
است که فرآیند ارزیابی کسب‌وکار، تشخیص مشکلات فروش، مدیریت مشتری،
فرصت‌های فروش، پیگیری، پیشنهاد خدمات، کمپین و تحلیل عملکرد را در یک
سیستم یکپارچه قرار می‌دهد.

## مسیر سیستم

مخاطب
→ ثبت کسب‌وکار
→ ارزیابی
→ تشخیص
→ برنامه اقدام
→ فرصت فروش
→ پیشنهاد خدمت
→ پیگیری
→ پرداخت
→ فروش
→ بازگشت
→ معرفی

## امکانات

- ارزیابی کسب‌وکار
- تشخیص نقاط قابل بهبود
- مدیریت مشتریان
- CRM
- فرصت‌های فروش
- مدیریت خدمات
- پیشنهاد قیمت
- پیگیری و اتوماسیون
- میز کار مشاور

- بازگشت مشتری

- بروزرسانی از GitHub

## فناوری

- WordPress
- PHP 8.1+
- MySQL / MariaDB
- WordPress REST API
- Bale Bot API

## نصب

1. فایل ZIP آخرین Release را دریافت کنید.
2. از پنل WordPress وارد افزونه‌ها شوید.
3. افزونه را نصب و فعال کنید.
4. تنظیمات Sana Sales و اتصال بله را انجام دهید.
